# Promo registry bot

Внутренний инструмент для учёта промо-материалов. Сотрудник отправляет файл макета в Telegram-бота с коротким описанием. Бот показывает, что собирается сделать, и после подтверждения сотрудника:

- кладёт файл в нужную папку на Google Диске;
- переносит прежнюю версию файла в архив;
- обновляет строку в таблице-реестре и записывает действие в журнал.

Пользоваться ботом могут только сотрудники из списка допуска. Публичного доступа нет.
